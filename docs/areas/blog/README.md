# 영역: 블로그

**상태 (2026-10-10):** 설계 전.

## 목적
웹사이트 유입을 위한 글. 로드맵 기준 주 1회 + 학부모용 월 2회, 콘텐츠 소재 7가지(합격생 작업물, 월말고사 현장, 발매곡 소개, 입시 팁, 합격 수기, 진로 가이드, 학부모 후기).

## 설계 때 정할 것
- 네이버 블로그(midi-pro)와 사이트 블로그(midipro.kr/blog)의 역할 분담. 같은 글을 그대로 두 곳에 올리면 네이버가 유사 문서로 판단해 노출을 낮출 수 있다.
- 원고 형식: `content/blog/YYYY-MM-DD-slug.md` (마크다운 + 제목·설명·태그 머리말)
- 글마다 OG 이미지 자동 생성, sitemap·RSS 포함
