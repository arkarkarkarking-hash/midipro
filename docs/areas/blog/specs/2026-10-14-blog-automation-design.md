# 블로그 자동화 설계서 — 홈페이지 블로그 + 네이버 블로그

- 작성일: 2026-10-14
- 상태: 승인됨 (grill-me 점검, 2026-10-13~14)
- 브랜치: `area/blog-setup`

## 1. 목표

- 1순위: 네이버 검색으로 들어온 천안·아산 학부모·학생의 **전화 상담**. 2순위: 구글 검색에서 midipro.kr 노출.
- 성과 판단은 원장님이 상담 때 적는 유입 경로가 기준이다. Claude는 보조 지표(검색어, 조회 글)만 월간 보고서로 정리한다.
- 홈페이지 블로그(`midipro.kr/blog`)는 정리된 원본 보관소, 네이버 블로그(`blog.naver.com/midi-pro`)는 검색 유입 창구.

## 2. 글 운영

### 발행 주기

주 3회, **월·수·금**.

| 종류 | 분류 값 | 횟수 | 재료 |
|---|---|---|---|
| 현장 글 (월말고사, 학생 작업물, 발매곡, 수업 모습) | `field` | 주 1회 | 원장님 사진 + 메모 필수 |
| 정보 글 (입시 팁, 진로 가이드, 학부모 질문, 장비·프로그램) | `guide` | 주 1~2회 | Claude 초안, 원장님은 사실 확인 |

- 첫 2주는 정보 글만 (미디 입시란, 미디프로 수업 방식, 장비·작업실 소개, 학부모가 자주 묻는 질문). 3주차부터 현장 글을 섞는다.
- 매달 말 Claude가 다음 달 주제표를 만들고 원장님이 확정한다. 주제표 파일: `content/blog/plan/YYYY-MM.md`.
- 재료가 없는 주는 정보 글로 채우고, 그렇게 했다고 알린다.

### 두 버전 원칙

원고 하나에서 **문장과 구성이 다른 두 버전**을 만든다. 같은 글을 그대로 두 곳에 올리면 네이버 유사 문서 판정으로 노출이 낮아질 수 있다.

| | 네이버용 | 홈페이지용 |
|---|---|---|
| 말투 | 친근한 구어체 | 정리된 설명체 |
| 길이 | 본문 800~1,200자 **필수**(공백 포함, 사진 자리·기호 제외), 소제목 3~4개 | 제한 없음 |
| 제목 | 지역·과목 키워드 포함 — `[천안 미디학원] 10월 월말고사 현장 — 고2 편곡 과제` | 내용 중심, 키워드 적게 |
| 사진 | 6~10장 (아래 4장 참고) | 3~5장 |
| 링크 | 글 끝에 홈페이지 링크 **1개만** | 없음 (사이트 하단 블로그 링크로 충분) |

### 규칙 (두 버전 모두)

- "합격곡" 금지 → "입시곡". 입시 결과와 곡을 연결하지 않는다.
- 숫자 요약(학교 수, 합격 건수), 최상급·자화자찬 표현("1등", "최고", "추천") 금지.
- 수강료 금액 금지. 연락은 전화(041-558-3101)만.
- 외부 이미지 금지. 학원 직접 촬영본과 코드로 생성한 그래픽만.
- 학생: 기본은 실명·얼굴 없음 ("고2 김OO 학생"). 메모에 `얼굴 OK: 2번 사진`처럼 명시된 사진만 얼굴 노출. 음원은 홈페이지에 이미 올라간 곡만 링크.
- 예전 네이버 글 50편은 옮기지 않는다 (유사 문서, 현재 규칙과 불일치 가능).

## 3. 주간 흐름

1. **재료 넣기 (원장님)** — `~/Desktop/블로그재료/YYYY-MM-DD 주제/`에 사진과 `메모.txt`. 저장소 바깥이라 원본 사진이 git에 들어가지 않는다.
2. **새벽 깨우기** — iMac이 매주 토요일 03:00에 잠자기에서 깨어난다 (`pmset repeat wake Sa 03:00:00`, 2026-10-14 설정 완료). iMac은 끄지 않고 잠자기, Claude 앱은 열어 둔다.
3. **주간 초안 작업 (Claude, 토 03:05 예약 작업)**
   1. 재료 폴더와 그달 주제표를 읽는다.
   2. 사진 손질: 긴 변 1,600px로 축소, EXIF(GPS·기기 정보) 제거, 동의 없는 얼굴 사진 제외. 홈페이지용은 R2(`media.midipro.kr/blog/...`)에 업로드.
   3. 그 주 월·수·금 3편 × 두 버전 작성.
   4. 금지어 검사 (4장).
   5. 미리보기 페이지 생성 → 원장님 휴대폰 알림.
4. **검토 (원장님)** — 미리보기를 보고 "좋아" 또는 수정 요청. Claude가 두 버전에 함께 반영.
5. **발행 (발행일)**
   1. Claude가 홈페이지 원고를 `main`에 반영 → 자동 배포. 홈페이지가 먼저여야 원본 날짜가 남고 네이버 글에 넣을 링크가 생긴다.
   2. 원장님이 네이버에: 본문 복사 → 붙여넣기 → **첫 문단·마지막 문단을 원장님 말투로 고쳐 쓰기** → 사진 끌어다 놓기 → 발행.

### 예약 작업이 안 돌 때

- 앱이 닫혀 있거나 잠자기 중이면 다음에 깨어날 때 이어서 실행된다.
- 원장님이 월요일까지 알림을 못 받으면 대화창에 "이번 주 초안"이라고 말하면 수동으로 실행한다.

## 4. 사진

| 글 종류 | 네이버 | 홈페이지 | 비고 |
|---|---|---|---|
| 현장 글 | 6~10장 | 3~5장 | 전경 1 + 작업 장면(손·화면·장비) 3~5 + 결과물(악보·DAW 화면) 1~2 |
| 정보 글 | 3~5장 | 대표 이미지 + 1~3장 | 사진 은행에서 고르고, 같은 사진을 네이버에 다시 쓰지 않는다 |

- 네이버는 원본 사진이 있는 글을 좋게 보는 경향이 있다는 것이 업계 통설이다 (네이버 공식 기준은 아님). 같은 사진 반복은 피한다.
- **사진 은행**: `~/Desktop/블로그재료/_사진은행/`에 작업실·강의실·장비·건물 외관 사진 30장 정도를 한 번 모아 두고 정보 글에 나눠 쓴다. 사용한 사진은 `_사용함/`으로 옮겨 재사용을 막는다.
- 네이버 본문에는 사진 자리를 `📷 사진 02`로 표시하고, 사진 파일은 `01.jpg`, `02.jpg` 순서로 한 폴더에 모은다.

## 5. 원고 파일

```
content/blog/
  YYYY-MM-DD-slug.md          홈페이지용 (사이트에 게시)
  naver/YYYY-MM-DD-slug.md    네이버용 (사이트에 게시하지 않음, 빌드 제외)
  plan/YYYY-MM.md             월간 주제표
```

머리말 (홈페이지용):

```yaml
title: 미디 입시, 무엇을 준비하나요
description: 한 줄 설명 (검색 결과·목록에 표시)
date: 2026-10-20
category: guide        # field | guide
tags: [미디입시, 천안]
cover: https://media.midipro.kr/blog/2026-10-20-slug/01.jpg   # 없으면 자동 생성 이미지
draft: true            # 승인 전 true, 발행일에 false
```

## 6. 홈페이지 블로그 화면

- `/blog` 목록: 최신순, 현장/정보 분류 거르기, 글마다 대표 이미지·제목·날짜·한 줄 설명.
- `/blog/<slug>` 글: 블루프린트 디자인 (격자, 고정폭 라벨), 본문 사진, 하단 전화 상담 버튼(기존 부품, 신호 주황), 같은 분류 다른 글 2편.
- 대표 이미지(OG) 자동 생성: 흑연색 격자 + 제목 + 날짜 + 분류. 기존 `src/pages/og/` 방식을 따른다. 네이버 대표 사진은 실제 사진을 우선하고, 사진 없는 정보 글에만 생성 이미지를 쓴다.
- 사이트맵 자동 포함, RSS(`rss.xml`)에 블로그 글 추가, 헤더 메뉴에 "블로그" 추가.
- `draft: true` 글은 빌드에서 제외.

## 7. 검사

- 홈페이지용: 기존 `npm run build`의 check-build가 그대로 적용된다 (금지어, 숫자 요약, img alt).
- 네이버용: 같은 금지어 목록에 "추천"을 더해, 원고 파일을 직접 검사하는 스크립트 `scripts/check-blog.ts`. 금지어 목록은 check-build와 한곳에서 공유한다.
- 추가 검사: 네이버 원고의 외부 링크 1개 이하, 본문 글자 수 800~1,200자, 사진 자리 표시와 사진 파일 수 일치.

## 8. 미리보기 페이지

- Claude가 주마다 비공개 Artifact 페이지로 만든다 (claude.ai, 휴대폰으로 열람 가능).
- 글마다 네이버용 / 홈페이지용을 나란히 보여 준다.
- 네이버용에는 "제목 복사", "본문 복사", "태그 복사" 버튼. 본문 복사는 소제목·굵은 글씨·줄바꿈만 있는 깨끗한 HTML로, 서식 찌꺼기가 붙지 않게 한다.
- 붙여넣기가 노출에 영향을 준다는 통설은 확인되지 않았다. 1~2달 뒤 월간 보고서 수치로 판단하고, 필요하면 직접 옮겨 적기와 비교한다.

## 9. 월간 보고서

- 매달 1일 예약 작업. 원장님 크롬(로그인 상태)에서 네이버 블로그 통계, 네이버 서치어드바이저, 구글 서치 콘솔을 **읽기만** 한다. 설정 변경·버튼 클릭 없음.
- 내용: 유입 검색어, 많이 읽힌 글, 다음 달 주제표에 반영할 점. 한 장 분량.

## 10. 사전 작업

- 구글 서치 콘솔: 도메인 속성(`midipro.kr`)으로 **이미 등록**, 사이트맵 제출됨 (DNS 확인이라 `PUBLIC_GOOGLE_VERIFY`는 필요 없음). 네이버 서치어드바이저도 등록 완료.
- 2026-10-14 발견: 첫 화면이 "중복 페이지, Google이 `https://www.midipro.kr/`을 표준으로 선택"으로 색인 안 됨. `www`·`http`는 이미 `https://midipro.kr/`로 301 이동 중. 원장님이 색인 생성 요청함 → 월간 보고서에서 표준 URL이 `midipro.kr`로 바뀌었는지 확인.
