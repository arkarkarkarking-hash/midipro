# 계정 운영 안내 (원장님용)

## 처음 한 번: 첫 관리자 계정

터미널에서 홈페이지 폴더로 이동한 뒤:

```bash
export PATH=~/.local/node/bin:$PATH
npx tsx scripts/create-admin.ts --login <아이디> --name <이름>
```

비밀번호를 두 번 물어봅니다. 입력하는 글자는 화면에 보이지 않고, 어디에도 저장되지 않습니다(암호화된 값만 저장).
아이디는 영문 소문자·숫자·밑줄(_) 4~20자, 비밀번호는 4~64자입니다.

## 계정 메모 (원장님 컴퓨터 = 원본)

계정은 원장님 컴퓨터의 메모 한 장으로 관리합니다. **메모를 저장하면 몇 초 뒤 사이트에 자동 반영**되고, 결과가 화면 오른쪽 위 알림으로 뜹니다.

- 메모 위치: `~/미디프로_계정/계정.txt` (홈 폴더, iCloud 동기화 안 됨). 바탕화면의 **계정 메모 열기** 아이콘으로 엽니다.
- 형식:

```
-관리자-
id : midipro / pw : 비밀번호 / name : 미디프로

-강사-
id : teacher_kim / pw : 비밀번호 / name : 김강사

-수강생-
id : stu_lee / pw : 비밀번호 / name : 이학생 / birth : 2010
```

| 메모에서 | 사이트에서 |
|---|---|
| 줄 추가 | 계정 만들기 |
| pw 수정 | 비밀번호 변경(그 계정은 모든 기기에서 로그아웃) |
| name·birth·구분 수정 | 그대로 수정 |
| 줄 삭제 | 비활성화(기록과 곡 연결은 남음, 다시 적으면 살아남) |

- 아이디: 영문 소문자·숫자·밑줄(_) 4~20자. 비밀번호: 4~64자, `/` 문자는 쓰지 않는다.
- 한 줄이라도 틀리면 아무것도 바꾸지 않고 알림으로 몇 번째 줄인지 알려 줍니다.
- 안전장치: 메모에 관리자가 없거나, 한 번에 3개 이상 비활성화하게 되면 자동 반영을 멈춥니다. 그때는 바탕화면의 **계정 반영** 아이콘을 더블클릭해 바뀔 내용을 보고 `y`로 반영합니다.
- 메모가 기준이므로, 관리자 화면에서 바꾼 계정 정보는 다음에 메모를 저장할 때 메모 내용으로 되돌아갑니다. 계정 추가·비밀번호·비활성화는 메모로 합니다(관리자 화면은 곡 연결·전화 클릭용).
- 자동 반영 기록: `~/Library/Logs/midipro-accounts.log` (비밀번호는 남지 않음)
- 켜기/끄기: `npx tsx scripts/accounts-sync.ts --install` / `--uninstall` (홈페이지 폴더에서)
- 메모를 잃어버리면 비밀번호는 복구할 수 없습니다(사이트에는 암호화된 값만 있음). 새로 적어 저장하면 그 비밀번호로 바뀝니다.

## 관리자 비밀번호를 잊었을 때

```bash
npx tsx scripts/create-admin.ts --login <아이디> --reset
```

새 비밀번호를 정하면 잠금·비활성 상태도 함께 풀립니다. (다른 계정은 관리자 화면에서 바꿉니다.)

## 관리자 화면 (https://midipro.kr/admin)

- **계정 만들기**: 아이디·이름·출생연도(선택)·역할·비밀번호를 입력하고 [만들기]. 정한 아이디와 비밀번호를 학생에게 직접 알려 줍니다. 연락처 등 다른 정보는 받지 않습니다.
- **비밀번호 재지정**: 학생이 비밀번호를 잊었거나, 5번 틀려 15분 잠겼을 때. 새 비밀번호를 정하면 잠금이 바로 풀리고, 그 계정은 모든 기기에서 로그아웃됩니다.
- **비활성화**: 수강이 끝난 학생. 바로 로그아웃되고 다시 로그인할 수 없습니다. [활성화]로 되돌릴 수 있습니다. 계정 삭제 기능은 없습니다.
- **곡 연결**: 수강생 줄의 [곡 연결] → 곡 검색 → 체크 → [저장]. 송캠프 곡처럼 한 곡을 여러 학생에게 연결할 수 있습니다. 학생은 마이페이지에서 연결된 곡만 듣습니다.
- **전화 클릭**: 최근 30일 동안 홈페이지의 [전화 상담] 버튼이 눌린 횟수(유입 경로·페이지·날짜별). 실제 통화 수와는 다를 수 있습니다.

## 역할

| 역할 | 볼 수 있는 화면 |
|---|---|
| 관리자 | 모든 화면 |
| 강사 | 마이페이지("준비 중" 안내) |
| 수강생 | 마이페이지(내 곡) |

14세 미만 학생의 보호자 동의는 학원 등록 서류로 받습니다.

## 개발자용: 내 컴퓨터에서 확인

- `npx wrangler d1 migrations apply midipro --local` 후 `.dev.vars`에 `TURNSTILE_SECRET=1x0000000000000000000000000000000AA`(Cloudflare 테스트 키)를 두고, `.claude/launch.json`의 `worker`로 `wrangler dev`를 띄운다(http://127.0.0.1:8787).
- 연습용 관리자: `npx tsx scripts/create-admin.ts --login <id> --name <이름> --local`
