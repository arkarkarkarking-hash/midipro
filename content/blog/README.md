# 블로그 원고

- 홈페이지용: `YYYY-MM-DD-slug.md` (날짜 = 발행일). 머리말 `title`(60자 이내), `description`(160자 이내), `date`, `category`(`field` 현장 / `guide` 정보), `tags`, `cover`(선택, `https://media.midipro.kr/blog/`만), `draft`(승인 전 `true`).
- 네이버용: `naver/<같은 slug>.md`. 머리말 `title`, `tags`, `photos`; 소제목 `## `, 사진 자리 `[[사진 NN]]`, 본문 800~1,200자. 사이트에는 게시되지 않는다.
- 월간 주제표: `plan/YYYY-MM.md`.
- 절차: `docs/areas/blog/weekly.md`.
